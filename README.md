# Курсовая работа — передача файлов по сети

Клиент-серверная программа на C++ с использованием Winsock.
Сервер принимает файлы от клиента и хранит их в папке `SavedFiles`. Клиент может отправить файл на сервер, посмотреть список файлов и скачать нужный файл обратно.

## Что находится в проекте

- `Server` — серверная часть;
- `Client` — клиентская часть.

Обе части собираются отдельно.

## Как собрать и запустить

Проект делался под Windows в Code::Blocks с MinGW.
Для работы с сетью используется библиотека `ws2_32`.

1. Открыть `Server/Server.cbp` и собрать проект.
2. Открыть `Client/Client.cbp` и собрать проект.
3. Сначала запустить сервер.
4. После этого запустить клиент и выбрать подключение к серверу.

Клиент подключается к `localhost` через порт `27015`, поэтому в текущем варианте сервер и клиент запускаются на одном компьютере.

## Работа с файлами

Для отправки файла клиенту нужно указать полный путь к нему.

Пример:

```text
C:\Users\User\Desktop\test.txt
```

При скачивании клиент получает список файлов с сервера. Нужный файл выбирается по его номеру в списке.

Файлы на сервере сохраняются в папке `SavedFiles`.

## Управление

В клиентском меню используются стрелки `UP` / `DOWN`, клавиша `ENTER` для выбора и `ESC` для выхода.

Если понадобится подключать клиент с другого компьютера, адрес сервера можно изменить в `IP_ADDRESS` в исходном коде клиента и пересобрать проект.
