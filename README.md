# Клиент-серверная передача файлов

Учебное приложение на C++ для передачи файлов между клиентом и сервером по TCP с использованием Winsock.

## Возможности

- подключение клиента к серверу по адресу `localhost` и порту 27015;
- отображение активных пользователей;
- отправка файлов на сервер;
- просмотр файлов серверного хранилища;
- скачивание файлов с сервера по номеру из списка;
- передача файлов блоками по 8192 байт.

## Сборка

Проект рассчитан на Windows и Code::Blocks/MinGW с поддержкой C++17.
В файлах проектов уже добавлена библиотека `ws2_32`.

1. Открыть `Server/Server.cbp` и собрать сервер.
2. Открыть `Client/Client.cbp` и собрать клиент.
3. Сначала запустить сервер, затем клиент.
4. Для скачивания файла открыть серверное хранилище и выбрать файл по его номеру в списке.

## Запуск

Текущая версия клиента подключается к серверу по адресу `localhost` и порту `27015`, поэтому сервер и клиент запускаются на одном компьютере.

Если понадобится использовать сервер на другом компьютере, адрес можно изменить в исходном коде клиента в константе `IP_ADDRESS` и пересобрать проект.

Файлы сервера сохраняются в папку `SavedFiles` рядом с исполняемым файлом сервера.

## Текущие ограничения

- нет авторизации и шифрования соединения;
- адрес сервера и порт 27015 заданы в исходном коде;
- размер файла хранится в типе `int`, поэтому проект не рассчитан на файлы размером более примерно 2 ГБ;
- интерфейс консольный;
- сетевой протокол учебный и предназначен прежде всего для локальной сети.

## Интерфейс

Клиент и сервер открываются в фиксированных консольных окнах. Размер окна менять не требуется. В клиенте раздел «Помощь» содержит краткую инструкцию по подключению, отправке и скачиванию файлов.
